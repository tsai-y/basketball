# ACA-Net 復刻原型：從影片到 Make／Miss

本文說明目前**程式實際做的運算**。依據 Zhang et al. (2024)，
DOI [10.3389/fnbot.2024.1471327](https://doi.org/10.3389/fnbot.2024.1471327)，
Figures 1–3 與 Eqs. 1–8。未公開細節採候選設定，完整對照見 README。

## 一、輸入如何代表整支影片

```text
約6秒原影片
→ 一次循序解碼，全片均勻保留50個時間位置
→ 每幀320×240縮為160×120，保留完整畫面
→ RGB / 255，再依ImageNet mean/std正規化
→ [N,3,50,120,160]
```

N是同批影片數；3是RGB；50是時間位置；120、160是高度、寬度。
這50個位置覆蓋整片，但相鄰輸入不一定是原片相鄰影格；取樣間距由原始幀數決定。
本版沒有加YOLO。每個影片仍提供一個Make／Miss標籤，不將50幀當50個獨立訓練答案。

## 二、ResNet50 是骨幹

ResNet50的2D卷積在每張影格使用同一組權重。實作時暫將N與T合併，
讓Conv2D接收`[N×T,C,H,W]`，處理後還原`[N,C,T,H,W]`。
四個stage包含3、4、6、3個bottleneck，共16個ACA插入點。

| 位置 | 還原後形狀（N=1，T=50） |
| --- | --- |
| 輸入 | `[1,3,50,120,160]` |
| Stem 7×7 Conv2D、stride2 | `[1,64,50,60,80]` |
| MaxPool、stride2 | `[1,64,50,30,40]` |
| Res2／layer1，3 blocks | `[1,256,50,30,40]` |
| Res3／layer2，4 blocks | `[1,512,50,15,20]` |
| Res4／layer3，6 blocks | `[1,1024,50,8,10]` |
| Res5／layer4，3 blocks | `[1,2048,50,4,5]` |
| 時間與空間平均 | `[1,2048]` |
| Linear，二分類 | `[1,2]` |

時間長度50在這條路徑保持不變。空間逐步縮小，通道數增加；通道是可學習特徵，
不代表某一通道已被指定為「球」或「籃圈」。baseline只逐幀處理並平均，
其影片輸出對輸入影格順序不敏感；加入LSTA後才有額外跨時間運算。

## 三、每個 bottleneck 裡放什麼

```text
block輸入 ──────────────────────────┐
   ↓                               │ residual（必要時投影尺寸）
1×1 Conv2D → BN → ReLU              │
   ↓                               │
ACA：LSTA(X) + TSCI(X)              │
   ↓                               │
3×3 Conv2D → BN → ReLU              │
   ↓                               │
1×1 Conv2D → BN                     │
   ↓                               │
逐元素相加 ←────────────────────────┘
   ↓
ReLU → 下一block
```

1×1卷積調整通道，3×3卷積處理空間鄰域，最後1×1展開通道。
殘差路徑把block輸入送至末端相加，提供較直接的資訊與梯度通路。
ACA在內部較窄的通道運算：四個stage的ACA通道分別64、128、256、512；
這不同於各stage輸出的256、512、1024、2048。

LSTA與TSCI接收**同一個X**，平行計算後相加；本版沒有將兩者前後串接。

## 四、LSTA：依影片內容整合時間資訊

### Gating先產生可調節的特徵

本版三個卷積區塊各包含Conv3D、InstanceNorm、ReLU：

```text
G = X + ConvBlock3D_3(ConvBlock3D_1(X) × sigmoid(ConvBlock3D_3(X)))
```

兩支路徑產生數值與控制訊號，以相乘調節特徵，再經另一個3D卷積和殘差相加。
3×3×3同時處理時間、高度與寬度鄰域。
Sigmoid依Figure2；文字與Eq.1沒有完全一致，已記為復刻假設。

### 短期分支產生每個通道／時間位置的權重

先把G的H、W平均：`[N,C,T,H,W] → [N,C,T]`，得到P。
P經兩層Conv1D：`C → C/16 → C`，kernel3，夾ReLU、末端Sigmoid，得到V。
V沿H、W廣播，再乘完整G形成Z。因此各channel和時間點可有不同權重，
同一channel／時間點的所有空間位置共用該權重。
此權重沒有「已定位投籃事件」的保證，也不是每個像素獨立的attention。

### 長期分支依全段摘要產生時間卷積核

同一P另經兩層Linear，沿T運算：`50 → 12 → 3`，夾ReLU、末端Softmax。
得到`Θ[N,C,K=3]`：每支影片、每個channel都有自己的三個非負權重，總和為1。
再以各自的Θ沿Z的時間維度做channel-wise convolution，保留T、H、W。

它的「長期」在於Θ由全50個時間位置共同生成；實際聚合核仍只有3個鄰近輸入位置。
這不等同於任意兩個時間位置直接互相attention。K=3、β=0.25、r=16均是待核對的候選值。

## 五、TSCI：逐幀調節通道與空間資訊

TSCI有三支路徑，每支都先做平均／最大池化並串接成兩個特徵面，
再經7×7 Conv2D、BatchNorm和Sigmoid產生權重，乘回該路徑輸入：

| 壓縮方向 | 保留、建立互動的方向 | 權重作用 |
| --- | --- | --- |
| C | H×W | 每個空間位置，共用於所有channel |
| H | C×W | 各channel／水平位置，共用於高度 |
| W | C×H | 各channel／垂直位置，共用於寬度 |

三路還原成原始維度後平均，得到TSCI(X)。TSCI在每個時間點使用共享的2D運算；
其本身沒有跨時間卷積。它可能強調有用區域，但沒有YOLO那樣的物件類別／框輸出。

## 六、影片分類

全部stage結束後，`[N,2048,50,4,5]`做時間與空間平均，得到`[N,2048]`。
二分類Linear輸出`[N,2]`的兩個logits，分別對應Miss=0與Make=1。
未來訓練使用CrossEntropyLoss；推論時才用Softmax轉成兩類機率。
目前沒有正式訓練與泛化成績；真實資料smoke只檢查tensor與輸出是否有限。

## 七、為何會有93.18M參數

一般C→C、kernel為k_t×k_h×k_w的Conv3D（無bias），參數為`C²×k_t×k_h×k_w`。
每個LSTA gating包含1×1×1與兩個3×3×3，因此是`55×C²`。

| Stage | ACA通道C | Blocks | Gating參數 |
| --- | ---: | ---: | ---: |
| Res2 | 64 | 3 | 675,840 |
| Res3 | 128 | 4 | 3,604,480 |
| Res4 | 256 | 6 | 21,626,880 |
| Res5 | 512 | 3 | 43,253,760 |
| 合計 | | 16 | 69,160,960 |

八類頭重建模型的參數分解：

| 部分 | 參數 |
| --- | ---: |
| ResNet50骨幹 | 23,508,032 |
| LSTA gating | 69,160,960 |
| LSTA短期分支 | 475,564 |
| 動態核生成 | 10,416 |
| TSCI | 4,800 |
| 八類Linear | 16,392 |
| 合計 | 93,176,164 |

換成二類頭只減少12,294參數，不能解釋與26.8M的巨大差異。
診斷性depthwise假設為24,222,884，也不等於26.8M，且未證實為作者設定。
目前可確定的是差異主要來自3D gating解讀；不能據此斷言論文錯誤或原模型不可重現。
