# 影片輸入：已採用、已否決與尚未啟用

更新：2026-11-16。當前版本：native_uniform50_whole_clip_eight_class_v1。

原生影片完整解碼 → 整段端點均勻取50幀 → BGR轉RGB → 全圖縮為寬160×高120 → 除255及ImageNet常數正規化 → CPU float32 [3,50,120,160]。

「整段」指50幀涵蓋片頭至片尾，不是把所有145–180張來源影格都送進模型。解碼量與模型輸入量是兩件事；RGB是三種顏色，尚未拆成投手／球／籃框三路特徵。

目前新增的主要成果是「資料清單、可重現接口、驗收證據與內容問題紀錄」，不是已完成背景消除、事件自動定位或模型效果改善。固定50×RGB×120×160，每片2,880,000個元素；裁切後仍輸出相同尺寸不會自動減少輸入量。

本輪沒有訓練、推論或test影片存取。既有訓練與每小時排程仍暫停。沒有聲稱達到90%或作者精確複刻。
