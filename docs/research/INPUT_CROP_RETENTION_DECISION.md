# 固定16支：時間／裁切採用判斷

日期：2026-11-16。結論：**不採用本輪固定5%空間裁切、時間裁切或兩者合併作正式預設**。正式輸入保持50幀RGB、160×120、整段時間範圍均勻取樣及全圖縮放。未訓練或開啟validation／test影片。

## 規則與範圍

使用原先固定16支train，每類2支、16個不同來源群組；沒有換片。這些樣本先前已看過，因此本輪是探索性比較，不能稱為盲式、獨立驗證或作者精確裁切。候選輸出前固定以下規則，不再針對結果調參。

| 版本 | 時間 | 空間 | 輸出 |
| --- | --- | --- | --- |
| base | 原生整段範圍均勻50幀 | 全圖縮放 | 50幀RGB、160×120 |
| space | 同base | 四周各裁5%，原圖座標[16,12,304,228) | 同上 |
| time | 頭尾各去掉floor(F/20)幀，剩餘範圍重新均勻取50幀 | 全圖縮放 | 同上 |
| both | 同time | 同space | 同上 |

所有版本維持既有RGB／ImageNet正規化；沒有新偵測模型、ROI追蹤、影像增強或標籤修改。候選只存在於對照工具，未接入正式loader。

## 技術結果

- 16支各唯讀解碼一次，產生64個CPU float32 `[3,50,120,160]` 張量，全部shape／有限值／contiguous及50個不同來源索引檢查通過。
- 16支來源SHA及base正規化張量SHA均與凍結基準一致。三項幾何檢查通過，短片裁切後不足50幀會拒絕，不補幀或循環。
- 四路每支皆2,880,000個輸入元素；輸入量比例為1。保留81%原圖面積只會在固定輸出尺寸下將目標線性放大約11.1%，不會讓模型輸入量減少19%。沒有量測訓練速度。

## 為何不採用

1. **固定去頭不等於去雜訊。** 樣本14開頭已見投籃動作／籃框附近球路脈絡，time從來源f7開始，原基準採用的f0、f2、f5均被移除。這不是精確出手／進球時刻標註，但足以拒絕「片頭必定只是空白」的假設。
2. **來源轉播內容仍在。** 樣本09的time輸出slot0至16仍是完整統計卡，17／50張；slot17為轉場。樣本10的both完整50幀仍見前景頭部遮擋與板凳席特寫。此數字僅描述該片，不能估算全資料比例。
3. **空間收益有限且必要脈絡安全性未充分成立。** 固定中央裁切不會移除中央統計卡或遮擋，部分俯視／仰視片段的籃板貼近上邊。保守裁切也會進一步減少邊緣脈絡；未據此宣稱籃圈整個消失或準確率降低。

不採用只針對這套固定比例規則。沒有證明所有裁切方法無效，也沒有證明全圖是最佳解。要採用內容感知裁切，需要可靠事件範圍與必要目標的保留依據，本輪沒有自行擴張成新的偵測／追蹤或模型訓練工作。
